# Mvind-them-flags

🚩Mind the flag🚩

Repositorio de write-ups de máquinas CTF, con el proceso completo: reconocimiento, enumeración, explotación y post-explotación

Cada máquina se documenta siguiendo la misma estructura: identificación de servicios, superficie de ataque, vector de entrada, explotación y escalada de privilegios hasta root o el flag final. 

No es un resumen de lo que funcionó: se explica también lo que se probó y no llevó a ningún sitio, porque ahí es donde realmente se entiende por qué funciona una técnica y no solo cómo se ejecuta.
